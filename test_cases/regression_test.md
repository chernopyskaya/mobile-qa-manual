# Чек-лист и результаты выполнения тестов: регрессионное тестирование

**Статус окружения:** Honor 8, OC Android 9.0 Pie, разрешение экрана 1080×1920, диагональ 5.5"

## Установка/Запуск/Обновление

- [x] **T1** — Приложение устанавливается на мобильное устройство без сбоев
- [x] **T2** — Приложение успешно запускается после его закрытия
- [x] **T3** — Приложение успешно обновляется
- [x] **T4** — Пользователь может посмотреть версию сборки приложения и дополнительную информацию
- [x] **T5** — При обновлении сохранились разрешения, выданные приложению
- [ ] **T6** — При обновлении сохранились настройки и введенные данные — ❌ **Failed** ([BR-10](#))
- [x] **T7** — При установке приложение запрашивает разрешение на доступ к геолокации

## Определение геолокации

- [x] **T8** — Приложение определяет геолокацию и отображает устройство на карте
- [x] **T9** — Если геолокация устройства пользователя определяется в городе с метро, то активной отмечена станция «Откуда», ближе к которой находится устройство
- [x] **T10** — Если геолокация устройства пользователя определяется в городе без метро, то станция «Откуда» не отмечена

## Прерывания

- [x] **T11** — Приложение стабильно работает при переключении с сети LTE на сеть 3G
- [x] **T12** — Приложение стабильно работает при переключении с сети LTE на сеть Wi-Fi
