# 🚇 Функциональное и регрессионное тестирование — Яндекс Метро

## 📌 О проекте

Проект посвящён ручному тестированию мобильного приложения **Яндекс Метро** после рефакторинга кода командой разработки.

В рамках проекта проведён анализ требований к приложению, разработаны чек-листы для функционального и регрессионного тестирования, выполнено тестирование на эмуляторе Android Studio и оформлены баг-репорты по обнаруженным дефектам.

Основная цель тестирования — убедиться, что затронутая рефакторингом функциональность работает корректно, а остальной функционал приложения не пострадал, и подготовить отчёт для принятия решения о выпуске новой версии в стор.

## 🎯 Задача

Команда Яндекс Метро провела рефакторинг мобильного приложения на Android — внесла правки в код. Чтобы выпустить новую версию, необходимо было:

- протестировать те части продукта, которых коснулись изменения;
- провести регрессионное тестирование и убедиться, что новую версию можно заливать в стор;
- по результатам проверок предоставить отчёт о тестировании менеджеру.

### 🧩 Этапы работы

**1. 🔍 Подготовка к функциональному тестированию**
Анализ требований, затронутых рефакторингом, и написание тестов на их основе в виде чек-листа.

**2. 🔁 Подготовка к регрессионному тестированию**
Составление чек-листа с учётом особенностей мобильного приложения:
- определение функциональности, взаимодействующей с мобильным устройством;
- фиксация мобильных проверок, связанных с этой функциональностью;
- учёт проверок, необходимых для любого мобильного приложения (например, тестирование обновления).

Примеры проверок особенностей мобильного приложения:
- 📶 поведение при переключении между типами сетей (3G, LTE, Wi-Fi);
- 🔄 работа после восстановления связи;
- 📍 определение геолокации;
- ✈️ работа при включении авиарежима;
- 🔀 переключение между приложениями;
- 📞 поведение при входящем звонке/уведомлении;
- 🔃 смена ориентации экрана;
- 🔍 масштабирование интерфейса;
- 🔋 включение режима энергосбережения;
- 🪫 работа при низком заряде аккумулятора и т. д.

**3. ✅ Выполнение тестирования**
Тестирование приложения по составленным чек-листам и оформление баг-репортов по найденным дефектам.
